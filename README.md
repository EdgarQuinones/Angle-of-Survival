# Angle of Survival

## About the Game

A 2D arena survival shooter where you fight off waves of monsters using a weapon that ricochets between enemies. Keep moving, aim carefully, and survive as long as possible!

Developed in approximately 7 hours for [Trijam #358](https://itch.io/jam/trijam-358). This was my first game jam and a great opportunity to experiment, learn, and build a complete playable game under a tight time constraint.

## Controls

- **W / A / S / D:** Move
- **Left Click:** Shoot
